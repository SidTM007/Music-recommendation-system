# A Linear Algebra Based Music Recommendation System

A music recommender that represents songs as vectors and finds similar songs using
dot product, norms, cosine similarity and PCA (eigenvectors).

## Live application
👉 https://music-recommendation-system-spyg4k6deefu6kxnvybq9n.streamlit.app/

## Files
- `music_recommender.py` – Streamlit application
- `Music_Recommender_Linear_Algebra.ipynb` – Jupyter notebook with step-by-step code
- `Music_Recommender_Presentation.pptx` – project presentation
- `requirements.txt` – libraries needed
